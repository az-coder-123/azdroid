# WifiDesk — Mouse Gestures & macOS Keyboard Shortcuts

> Complete reference for navigation keys, trackpad gestures, and input injection.

---

## 🖱️ Mouse & Trackpad Gestures

| Gesture / Button | Action | Android Equivalent |
| :--- | :--- | :--- |
| **Left Click** | Tap | Primary Touch Event |
| **Left Click + Drag** | Swipe / Scroll / Pan | Touch Drag Motion |
| **Right Click** | Secondary Click | System `BACK` Key |
| **Middle Click** | Scroll Wheel Press | System `HOME` Key |
| **Scroll Wheel / 2 Fingers** | Vertical / Horizontal Scroll | Touch List Scrolling |

---

## ⌨️ macOS Keyboard Shortcuts

| Shortcut | Function | Description |
| :--- | :--- | :--- |
| <kbd>Cmd</kbd> + <kbd>H</kbd> | Home Screen | Navigates immediately to Android Home |
| <kbd>Cmd</kbd> + <kbd>Backspace</kbd> | Back | Simulates Android Back navigation |
| <kbd>Cmd</kbd> + <kbd>Tab</kbd> | App Switcher | Opens Android Recent Apps list |
| <kbd>Cmd</kbd> + <kbd>S</kbd> | Capture Screenshot | Lossless PNG saved to `~/Downloads` & copied to macOS clipboard (`⌘V`) |
| <kbd>Cmd</kbd> + <kbd>K</kbd> | Text Injector | Opens modal to send Unicode / Vietnamese text |
| <kbd>Cmd</kbd> + <kbd>R</kbd> | Rotate Screen | Rotates video viewport by 90° clockwise |
| <kbd>Cmd</kbd> + <kbd>O</kbd> | Screen Toggle | Toggles physical device screen off to save power |
| <kbd>Escape</kbd> | Back | Closes dialogs or navigates back |
