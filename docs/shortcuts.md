# DeskDroid — Mouse Gestures & Keyboard Shortcuts

> Complete reference for navigation keys, trackpad gestures, and input injection.

---

## 🖱️ Mouse & Trackpad Gestures

| Gesture / Button | Action | Android Equivalent |
| :--- | :--- | :--- |
| **Left Click** | Tap | Primary Touch Event |
| **Left Click + Drag** | Swipe / Scroll / Pan | Touch Drag Motion |
| **Right Click** | Secondary Click | System `BACK` Key |
| **Middle Click** | Scroll Wheel Press | System `HOME` Key |
| **Scroll Wheel / 2 Fingers** | Vertical / Horizontal Scroll | Touch List Scrolling |

---

## ⌨️ Keyboard Shortcuts

> The tables use the macOS **Cmd** key. On Windows (and Linux) every shortcut uses **Ctrl** instead, for example <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd>. Tooltips in the app always show the keys of the running platform (`⌘⇧S` on macOS, `Ctrl+Shift+S` on Windows).

| Shortcut | Function | Description |
| :--- | :--- | :--- |
| <kbd>Cmd</kbd> + <kbd>H</kbd> | Home Screen | Navigates immediately to Android Home |
| <kbd>Cmd</kbd> + <kbd>Backspace</kbd> | Back | Simulates Android Back navigation |
| <kbd>Cmd</kbd> + <kbd>Tab</kbd> | App Switcher | Opens Android Recent Apps list |
| <kbd>Cmd</kbd> + <kbd>S</kbd> | Full Screenshot | Lossless full-screen PNG saved to `~/Downloads` & copied to clipboard (`⌘V`) |
| <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | Area Screenshot | Drag marquee to crop region on phone screen; saves & copies to clipboard |
| <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>R</kbd> | Screen Recording | Starts / stops hardware MP4 recording saved to `~/Downloads` |
| <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>I</kbd> | Install APK | Opens APK Sideload & Manager dialog with metadata inspection |
| <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>L</kbd> | Device Logcat | Opens real-time logcat inspection, filtering & recording console |
| <kbd>Cmd</kbd> + <kbd>U</kbd> | Send Files | Native macOS Finder file picker to send files/media/APKs to Android |
| <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> | Device Files | Opens Android File Manager dialog with quick folders & download to Mac |
| <kbd>Cmd</kbd> + <kbd>K</kbd> | Text Injector | Opens modal to send Unicode / Vietnamese text |
| <kbd>Cmd</kbd> + <kbd>R</kbd> | Rotate Screen | Rotates video viewport by 90° clockwise |
| <kbd>Cmd</kbd> + <kbd>O</kbd> | Screen Toggle | Toggles physical device screen off to save power |
| <kbd>Escape</kbd> | Back | Closes dialogs or navigates back |
