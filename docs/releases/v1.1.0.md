## Azdroid v1.1.0 (macOS)

### New
- **Multi-touch:** two-finger pinch and rotate from the trackpad, or Alt + drag with a mouse.
- **Live trackpad scrolling:** two-finger scrolling drags the phone screen in real time, so lists fling as they do on the phone.
- **Unicode text:** the text input (Cmd + K) pastes Vietnamese, CJK, and emoji intact.
- **Screen Off (Cmd + O):** turns the phone's display off while mirroring and control continue.
- **Keep Phone Awake:** sun icon in the side toolbar, on by default. The phone does not sleep while mirroring, and no phone setting is changed.
- **Audio forwarding (Android 11+):** the phone's sound plays on the computer.
- **ADB is bundled:** no separate ADB installation is needed on macOS.

### Improved
- scrcpy-server upgraded from v2.1 to **v5.0.1**: mirroring works on Android 14 QPR3, 15, and 16.
- Touch, keys, and the Back, Home, and App Switch buttons go through the scrcpy control socket, which is faster and more reliable than `adb shell input`.
- The side toolbar no longer overflows in small windows.

### Known Limitations
- The app is not signed with an Apple Developer ID. If macOS blocks it, run `xattr -cr /Applications/Azdroid.app` once.
- The bundled MCP server (`deskdroid-mcp`) is built for Intel only; on Apple Silicon it needs Rosetta 2.
- No Windows package for this version yet. The latest Windows (Preview) package is [v1.0.1](https://github.com/az-coder-123/azdroid/releases/tag/v1.0.1).

### Verify the Download

