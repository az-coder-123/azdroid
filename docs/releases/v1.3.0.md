## DeskDroid v1.3.0 (macOS & Windows)

### New
- **Extended MCP Gesture & Automation Tools (61 tools total):**
  - `android_scroll`: Directional smooth scrolling (up, down, left, right) with customizable pixel distance, duration, and anchor coordinates.
  - `android_pinch_gesture`: Two-finger pinch in / pinch out zoom gestures with configurable center point, finger spacing, and step counts.
  - `android_rotate_gesture`: Two-finger rotation gesture around a focal point with configurable start and end angles in degrees.
  - `android_wait_for_condition`: Host-level polling tool for automated agent workflows, evaluating conditions (`element_exists`, `element_gone`, `text_contains`, `activity_resumed`) with timeout and interval options.
  - **ROI Screenshot Cropping:** `android_take_screenshot` supports an optional `crop_rect` parameter (`x`, `y`, `width`, `height`) to crop region-of-interest directly upon capture.
  - **Compound Batch Actions:** `android_batch_actions` compiler now executes `double_tap`, `pinch`, and `rotate` steps in sequence.
  - **Normalized Percentage Coordinates:** Gestures and touch inputs accept fractional (`0.0`–`1.0`) and percentage strings (e.g., `"50%"`) in addition to absolute pixel coordinates.

### Improved
- **Standalone MCP CLI Decoupling:** Decoupled `AppLogger` from the Flutter foundation framework, allowing `deskdroid-mcp` to run as a lean, pure Dart CLI process with zero Flutter framework dependencies.
- **Modular Gesture Architecture:** Extracted dedicated gesture executors and motion interpolators adhering strictly to Single Responsibility Principle.

### Known Limitations
- The app is not signed with an Apple Developer ID. If macOS blocks it, run `xattr -cr /Applications/DeskDroid.app` once.
- The bundled MCP server (`deskdroid-mcp`) is built for Intel only; on Apple Silicon it runs seamlessly via Rosetta 2.
- On Windows, the build is not code-signed. If SmartScreen shows *"Windows protected your PC"*, click **More info → Run anyway**.

### Verify the Download
Compare the SHA-256 of the ZIP with `RELEASE/SHA256SUMS.txt` (macOS) or `RELEASE/SHA256SUMS-windows.txt` (Windows) in the repository:
```bash
shasum -a 256 DeskDroid-v1.3.0-macOS.zip
shasum -a 256 DeskDroid-v1.3.0-Windows-x64.zip
```
