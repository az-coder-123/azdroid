## Azdroid v1.2.1 (macOS)

### Fixed
- **Wi-Fi devices stuck as "unauthorized":** the phone asks "Allow USB debugging?" only when a connection opens, and on a new computer that first prompt often appeared during auto-discovery and timed out unseen. Mirroring then failed on every retry. Azdroid now reconnects an unauthorized Wi-Fi device before reporting the error, so the prompt appears again: watch the phone, tap **Allow**, and retry.

Everything else is as in [v1.2.0](https://github.com/az-coder-123/azdroid/releases/tag/v1.2.0).

### Known Limitations
- The app is not signed with an Apple Developer ID. If macOS blocks it, run `xattr -cr /Applications/Azdroid.app` once.
- The bundled MCP server (`deskdroid-mcp`) is built for Intel only; on Apple Silicon it needs Rosetta 2.
- No Windows package for this version yet. The Windows (Preview) package [v1.2.0](https://github.com/az-coder-123/azdroid/releases/tag/v1.2.0) already includes this fix.
