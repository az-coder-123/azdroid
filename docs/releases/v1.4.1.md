## Azdroid v1.4.1 (macOS)

### New
- **In-App Software Update & Version Discovery System** ([docs](../features/in-app-updates.md)):
  - **Ambient Toolbar Indicator:** An unobtrusive status icon in the AppBar displays a notification badge dot when a newer version is released on GitHub.
  - **Contextual Notification Banner:** A dismissible card appears at the top of the discovery dashboard when an update is available.
  - **macOS-Native Update Dialog:** Rich modal interface showcasing release titles, publish dates, full markdown changelogs, asset file sizes, and 1-click download actions.
  - **Semantic Versioning Engine:** Numerical SemVer comparison (`MAJOR.MINOR.PATCH+BUILD`) guaranteeing accurate version comparisons without string-sorting quirks.
  - **Rate-Limit & Offline Guard:** Automatic checks are throttled to 12-hour intervals to protect GitHub API limits, failing gracefully without obstructing startup or device mirroring.

### Improved
- **Universal Responsiveness:** Adaptive dialog layouts prevent `RenderFlex` overflows across constrained windows and varied desktop display scalings.
- **Strict Architecture Boundaries:** The updater feature is completely decoupled and wired at the composition root using `flutter_bloc` and dependency injection (`updater_di.dart`).

### Fixed
- Pinned device log dialog header outside high-frequency stream rebuilds to guarantee immediate close button responsiveness.

### Known Limitations
- The app is not signed with an Apple Developer ID. If macOS blocks it, run `xattr -cr /Applications/Azdroid.app` once.
- The bundled MCP server (`azdroid-mcp`) is built for Intel only; on Apple Silicon it runs via Rosetta 2.
- Windows: no new build in this release; use the [v1.3.0 Windows package](https://github.com/az-coder-123/azdroid/releases/tag/v1.3.0).

### Verify the Download
Compare the SHA-256 of the ZIP with `RELEASE/SHA256SUMS.txt` in the repository:
