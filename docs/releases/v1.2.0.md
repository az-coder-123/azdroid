## DeskDroid v1.2.0 (macOS)

### New
- **MCP server status:** a hub icon in the device list toolbar shows whether the bundled MCP server runs, which AI clients (Claude Desktop, Cursor, Antigravity) are set up to use it, and how many AI sessions are connected. Its panel copies the client configuration with the right path.
- **Live AI activity:** the panel lists each AI session and its recent tool calls, and the mirroring page shows a banner while an AI is controlling that device. Only tool names, devices, results, and durations are recorded, never what the AI types.

### Improved
- **Mirroring controls:** the controls now sit in two vertical docks beside the phone; the bottom bar is gone. The power button is at the top in red, Inject Text is at the top of the side toolbar, the Logcat console at the bottom, and Keep Phone Awake moved to the hardware controls.
- **Showcase and User Guide:** keyboard shortcuts match your OS (Cmd on macOS, Ctrl on Windows), and categories show how many features they hold.

### Fixed
- The MCP tool `android_get_current_app` failed on Android 10 phones and while the lock screen or notification shade was open. It now names the app and the window in front of it.

### Known Limitations
- The app is not signed with an Apple Developer ID. If macOS blocks it, run `xattr -cr /Applications/DeskDroid.app` once.
- The bundled MCP server (`deskdroid-mcp`) is built for Intel only; on Apple Silicon it needs Rosetta 2. The new status panel tells you when Rosetta is missing.
- No Windows package for this version yet. The latest Windows (Preview) package is [v1.0.1](https://github.com/az-coder-123/desk-droid/releases/tag/v1.0.1).

### Verify the Download
Compare the SHA-256 of the ZIP with `RELEASE/SHA256SUMS.txt` in the repository:
```bash
shasum -a 256 DeskDroid-v1.2.0-macOS.zip
```
